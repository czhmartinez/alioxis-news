# Cover images（内容差异化，禁止千篇一律）

缺图时必须生成封面；禁止空菱形 placeholder。

## 原则（用户 2026-09-14）
- **每条新闻一张独特画面**，按标题／摘要定制主体与场景；禁止全站同一刊头模板、同一色带排版、同一扁平符号语言。
- 旧版「新闻刊头色带 + 单符号」仅作实验，**日常停用**（观感千篇一律，差于内容场景图）。
- 同题多条也要换构图／主体／景别，不能只换一行字。

## 风格按内容（GenerateImage 16:9）
1. 硬件／芯片／设备 → 写实产品摄影
2. 应用／Agent／IDE／技能 → 半写实工作台或 UI 场景（每条道具不同）
3. 商业／融资／IPO／诉讼／监管 → 新闻摄影／纪实，主体随新闻变
4. 安全／武器／威胁情报 → 偏纪录片张力，避免血腥；主体明确（报告、屏幕、设施隐喻）
5. 研究／模型发布 → 实验室或抽象但**可辨认该模型／公司**的视觉锚点
6. 视频／音乐／创意工具 → 与作品形态相关的视觉，勿通用科技桌

## 禁止
- 全站统一色带刊头、万能文档图标、千篇一律会议室／浅景深办公大片
- 默认抽象几何壁纸
- 同一提示词骨架只改关键词

## 产出
1. GenerateImage（16:9），提示词写清：**具体主体、构图、光影、与该条新闻的对应关系**
2. 压到约 960 宽 JPEG quality ~72（约 40–100KB）→ `assets/covers/`
3. `image` 写成 `/assets/covers/<file>.jpg`，再 `node build.js`，最后 `scripts/publish-to-cvm.sh`
