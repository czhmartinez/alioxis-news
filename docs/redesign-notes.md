# 前端重做说明（v2）

只改展示层；`data/`、抓取与部署脚本、`build.js` 里的数据读取 / 去重 / 聚合逻辑都没动。

## 为什么重做导航
原来的 7 个标签其实分属五种不同维度：要闻、大V（内容类型）／AIHOT 日报（内容来源）／周报（时间尺度）／专题、人物（检索维度）／快讯（信息密度）。
放在同一排并列，读者无法形成统一预期。v2 把它们分成两组：

- **内容流**（并列的四种内容形态）：要闻 · 快讯 · 大V视野 · 简报
- **索引**（进入全部内容的轴线）：专题 · 人物 · 归档（按主题 / 按人 / 按日期）

AIHOT 日报与周报合并为「简报」（日报 / 周报切换）；人物并入大V的作者栏，同时保留完整名册作为索引。

## 每个模块一种版式
| 模块 | 形态 |
|---|---|
| 要闻 | 报纸头版：头条大图 + 两条次头条 + 紧凑列表 |
| 快讯 | 电讯时间线：时间 · 标题 · 来源，无图无摘要，按发布时间倒序、按日分组，日期标题吸顶 |
| 大V视野 | 观点流（引号标题）+ 左侧作者栏，点作者筛选；手机端变为顶部头像条 |
| 简报 | 居中单栏的订阅邮件：信头 + 编号条目；周报为「日期栏 + 当日要点」 |
| 专题 | 分栏看板，每栏前 5 条，可展开全部 |
| 人物 | 名册卡片：头像、活跃度条、标签、最新一条 |

视觉语言沿用 v1：暖白纸张底 / 自动暗色（◐ 可切换）、衬线标题、单一朱红强调色。

## 兼容
- URL：`/`、`/YYYY-MM-DD/`、`/archive/`、`archive.json` 不变；`?tab=ai|flash|v|digest|topics|creators`，简报用 `&view=daily|weekly`
- 旧链接 `?tab=aihot` / `?tab=weekly` 自动映射到简报对应视图
- 切换日期时保留当前模块；专题 / 人物与日期无关，自动隐藏日期条
- 封面缺失时自动退回纯文字排版

## 使用
覆盖 `build.js`、`assets/styles.css`、`assets/app.js`（以及 README.md），然后 `node build.js`。
